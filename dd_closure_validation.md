# Collective transparent-node validation

Status: optional research extension; not a parameterization route.

Dislocation dynamics will not parameterize the governing model. Neither the legacy domain-count law nor a prescribed `m(rho,T)` is accepted. The baseline is the independent-node EXP-floor law.

The only current collective candidate is derived from event-to-event stress transfer. Its branching matrix is `B_ij=integral lambda_i[exp(V_i* Delta tau_ij/(k_B T))-1]dt`, with susceptibility controlled by its spectral radius. Multi-hit behavior is represented, if needed, by a relaxing shot-noise stress state rather than a density switch.

The extension is promoted only if target observations reject the independent baseline in relevant higher-order or transient quantities and if one parameter set passes held-out rate/temperature conditions. Otherwise it remains an uncertainty ablation.

The literature does not support replacing this gate with an empirical multi-hit multiplier. First-pass versus repeat-pass conditioning is mechanistically plausible, and glissile/shearable junctions can still harden; neither fact supplies a scalar closure. Promotion therefore requires event parentage, signed transfer, contact conditioning/reset time, and held-out burst/correlation observables. The current DDD context lacks that cadence and remains structural evidence only.
