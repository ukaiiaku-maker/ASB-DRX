## Signed state, flux, and reaction definitions

For each in-plane slip family \(a\), the V19 branch carries nonnegative
\(\rho_{m,a}^{\pm}\), \(\rho_{f,a}^{\pm}\), and
\(\rho_{w,a}^{\pm}\), plus bounded wall order \(q_w\).  The legacy scalar
forest and wall arrays are exact sums used by mature v34 consumers.

Mobile populations use the production Orowan velocities and opposite-sign
conservative advection,

\[
\partial_t\rho_{m,a}^{\pm}
+\nabla\!\cdot(\pm\mathbf v_a\rho_{m,a}^{\pm})=S_{m,a}^{\pm}.
\]

Wall capture is limited to newly arriving mobile flux.  Release transfers wall
line back to the same signed mobile family.  Neutral annihilation removes equal
positive and negative wall populations.  Every rate uses

\[
\Delta G^\ddagger=\Delta H^\ddagger_{EXP-floor}-T\Delta S^\ddagger,
\quad
\Delta H^\ddagger=H_0[f+(1-f)e^{-a(|\tau|/\tau_c)^n}].
\]

No wall source uses orientation, an orientation gradient, a recognition mask,
or the particle support.  Wall order approaches a state determined by the
evolved wall fraction and signed polarization.  The ordering benefit in the
common phase-owned energy is weighted by this explicit \(q_w\), so an unsigned
dense tangle receives no ordered-boundary credit.

The admissible tangent basis is generated by the actual conservative columns

\[
m_a^+\leftrightarrow f_a^+,\quad
m_a^-\leftrightarrow f_a^-,\quad
f_a^+\leftrightarrow w_a^+,\quad
f_a^-\leftrightarrow w_a^-,

The Fourier-space operator includes those Arrhenius reaction mobilities,
opposite-sign advection, physical diffusion, density/order gradient energies,

numerical tolerance.  This wavelength is comparable to the analyzed domain
scale and is not accepted as a physical wall-selection prediction.
