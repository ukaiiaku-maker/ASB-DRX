# V43 persistent geometry and event kinematics

## Representation and scope

V43 adds an optional periodic lattice-line state to the production V24
mechanical wall state.  It is a discrete geometric channel, not a reconstructed
microscopic history and not a stand-alone DDD model.  The V42
geometry-neutral reservoir conversion remains the exact disabling comparator.

For Burgers family `a` and sign `s`, the retained state contains signed swept
plaquette quanta `q[a,s]`, their Burgers-weighted swept area, oriented x/y
links, the actual Burgers vector retained at event time, and an accepted-event
counter.  A newly prepared loop is explicitly labeled representation
initialization: it receives no heat and makes no claim about prior evolution.

The present 2-D plaquette normal is `e_z`.  Because a general BCC Burgers vector
need not lie in that plane, this is a generic climb/cross-slip surface channel,
not an assertion of glide on an arbitrary BCC plane.  Off-lattice nodes,
three-dimensional junction products, and cross-family Burgers reactions remain
unrepresented and fail closed.

## One discrete chain owns geometry and kinematics

On the periodic grid, a counter-clockwise plaquette field has link boundary

```text
e_x(i,j) = q(i,j) - q(i,j-1)
e_y(i,j) = q(i-1,j) - q(i,j).
```

The node balance is the discrete boundary-of-boundary identity

```text
e_x(i,j)-e_x(i-1,j) + e_y(i,j)-e_y(i,j-1) = 0.
```

It is verified from retained links at every validation and prevents an event
from silently creating an endpoint.  The Burgers-weighted links are the same
boundary applied to the retained Burgers-area field; they are not independently
assigned.

For cell volume `dx^2 h`, the family plastic distortion generated by swept
area is

```text
beta_p[a] = (sum_s B_swept[a,s]) / (dx^2 h) tensor e_z.
```

The authoritative family Nye increment is then evaluated with the production
spectral complex,

```text
Delta alpha[a] = -Curl_h(Delta beta_p[a]).
```

Consequently `sum_a Delta alpha[a] + Curl_h(Delta beta_p) = 0` to roundoff,
without a post-step projection.  Scalar ordered line density is the link
length shared equally by adjacent cells and divided by cell volume.  Its first
moment uses the same links with orientation rather than magnitude, which gives
`norm(kappa) <= rho`.  Shared links cancel when adjacent swept plaquettes join,
so a bow or expansion can change line length; that change enters the declared
wall energy instead of being incorrectly constrained to zero.

## Finite-rate and complete-energy transaction

The constitutive proposal fixes cell, family, Burgers sign, and direction.
Kinetics limits its extent using

```text
Delta H* = H0 [f + (1-f) exp(-a (tau/tau_c)^n)]
Delta G* = Delta H* - T Delta S*
rate = nu exp(-Delta G*/kB T),
```

with the existing explicit negative-barrier drag/reject policy.  Activation
entropy enters once; a constant entropy and attempt frequency remain
identifiable only through their product.  The finite extent is bounded by
`rate*dt` and the registered per-step cap.  The direction is never replaced by
an energy-minimizing direction.

Candidate geometry, density, moments, `beta_p`, and family Nye are built on
copies.  At fixed total strain the acceptance energy is

```text
Delta Phi = Delta F_wall + Delta U_elastic - W_external.
```

`Delta F_wall` is the complete production extensive energy, including the
ordered-gradient term.  `Delta U_elastic` is recomputed by the nonlocal elastic
solver using the candidate `beta_p`.  External work is zero in physical V43
responses; nonzero work exists only in explicitly labeled manufactured
verification.  A deterministic event publishes only when `-Delta Phi` is
nonnegative within the scale-aware tolerance.  Accepted release becomes heat
once; rejection returns the original state object and exactly zero heat.

Geometry-neutral ordering is now evaluated by this same complete-energy guard
and deposits identical heat in topology-enabled and topology-disabled controls.
This removes the V42 first-step `0.01204 K` attribution ambiguity: the heat
belongs to the accepted shared ordering reaction, not to a rejected geometry
trial.  A checkpoint reload never redeposits it.

## Signed reservoir transfer correction

For fixed tangle/ordered labels the implemented signed transfer selects the
donor by the sign of the extent.  Positive extent moves tangle to ordered;
negative extent moves ordered to tangle.  The moved first moment is taken from
that actual donor.  Polarized negative extent, exhausted donor, and exact-zero
tests pass.  Thus the implementation is equivalent to the signed formulas in
the V43 directive; V42's prose using `abs(xi)` without explicitly swapping the
donor was incomplete documentation, not the executed map.

## Evidence and claim boundary

`v43_nonzero_geometry_event.json` contains a finite accepted event, exact
Nye/curl and endpoint identities, complete energy/heat accounting, a rejected
atomic rollback, a second event consuming the evolved first-event state,
bitwise checkpoint continuation, translation symmetry, and physical segment
refinement.  `v43_physical_response.json` exercises the route inside the full
production mechanics with zero external event work and a disabled control.

This qualifies the represented event type and its ownership.  It does not
qualify spontaneous wall formation, a persistent LAGB, DRX, strict ASB, or a
material calibration.
